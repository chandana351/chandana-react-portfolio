# Chandana React Portfolio

A professional React + Vite frontend portfolio for Chandana.

## Stack
- React.js
- Vite
- JavaScript
- CSS
- Lucide React icons

## Run locally in VS Code / PowerShell

```powershell
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Build

```powershell
npm run build
```

## Before deploying

1. Replace the portfolio URL in `src/main.jsx` if you no longer use the old URL.
2. Add your final PDF as `public/resume.pdf`.
3. Verify every GitHub and Live Demo link.
4. Replace any project that you don't want publicly shown.
5. Deploy the `dist` output using your preferred hosting service.

## Important

The portfolio intentionally does not claim backend experience that is not confirmed. The displayed skills focus on the frontend technologies used in the resume.

## Profile photo
The uploaded professional profile photo is included at `public/profile.png` and is displayed in the hero card.
